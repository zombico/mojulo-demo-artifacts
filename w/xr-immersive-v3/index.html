XR immersive test v3

Open this page directly in the native Meta Browser on the Quest — not through the Muse app, not through Link / Air Link / Virtual Desktop. Tap a button with the controller trigger.

Why v3? v2 already tried a plain request and a WebGL request, both with the same error on this headset, while the official WebXR sample went fully immersive. So v3 does not repeat one button: it tries four different session paths in one page, and every result is printed here in large text, so a failure is readable with the headset on.

If a button works, you should go immersive immediately. The three.js button puts you in a small room (floor, back wall, teal sofa on the left, wooden table ahead, red cube on the right). Look around only — no stick movement in v3. Exit with the system button. The raw buttons just show a solid blue world — that still counts as immersive, it only proves the session started.
