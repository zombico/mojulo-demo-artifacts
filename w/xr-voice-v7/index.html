XR test v7 — one DICTATE button, IN VR

TEST PAGE ONLY — not Maison3D yet. No keys, no keyboard, no exit. You are right: v6 only took you out of the experience back to the browser window, and the system keyboard never launched in XR. That workflow is not good enough.

So v7 does dictation inside VR, with one button, and it does not use the system keyboard or the missing SpeechRecognition API at all. Instead: press DICTATE once to start recording your voice with the headset mic, speak, press DICTATE again to stop. The page then transcribes the recording locally in the browser with a small Whisper model (no server, no API key, audio never leaves the headset), and runs the transcribed command in the room. You stay in VR the whole time.

Do these two steps on the flat page first, before ENTER VR — they need to happen where you can see progress, and mic permission is easier there:

  1. Tap Allow mic and allow the microphone when asked.
  2. Tap Load voice model and wait until it says loaded. First download is ~40 MB and can take a minute on Wi-Fi; afterwards the browser caches it.

Then tap ENTER VR. In VR, look ahead for the one big button: DICTATE. Press it once (it turns red, panel says Listening…), speak a command like “make the sofa red”, press it again. The panel will say Transcribing… (this can take ~10 seconds), then show what was heard and change the room.

If the model or mic fails, the panel will say so in plain text — that is still a useful result. Flat typed commands still work as a debug fallback, but they are not the VR path.
