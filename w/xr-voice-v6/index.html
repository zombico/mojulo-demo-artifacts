XR test v6 — one DICTATE button

TEST PAGE ONLY — not Maison3D yet. No keys, no QWERTY, no presets. Just one button that triggers dictation.

Honest limitation, so the button does what it actually can: the Quest system keyboard cannot appear while you are inside an immersive-vr session (DOM overlay is AR-only, and the browser hides all DOM in VR). So a button inside VR cannot summon the keyboard there. What the one button can do is start the dictation workflow:

In VR: point at the big green DICTATE button in front of you and pull the trigger. It exits VR back to this flat page, focuses the command box, and tells you to dictate. On the flat page: tap the keyboard's microphone button, dictate a command (e.g. “make the sofa red”), tap Send, then tap ENTER VR again — the change is in the same room, so it shows up in VR.

That is the simplest version that actually works with the browser as it is today. Staying inside VR while dictating would need a different route — recording audio in VR and transcribing it on a server or locally — not the system keyboard.
