XR test v5 — chat box and keyboard IN VR

TEST PAGE ONLY — not Maison3D yet. Short answer to the DOM question: a normal HTML chat box + the Quest system keyboard cannot appear inside an immersive-vr session. DOM overlay is an AR-only feature in the spec, and Meta does not implement it for VR. That is why v4's overlay never showed up in VR, even though flat dictation worked.

So v5 does it the only way that works in VR: the chat box and keyboard are built in 3D, inside the scene itself. No DOM, no system keyboard, no SpeechRecognition API needed. In VR, point a controller ray at a key and pull the trigger to type, then hit SEND. The typed text appears on the 3D panel above the keyboard, and SEND runs the same command parser as v4.

Open directly in the native Meta Browser on the Quest. Flat page still works the same as v4: Dictate (keyboard mic) or type, Send, then ENTER VR — that change should already be in the room. In VR, look ahead: the keyboard is in front of you, about 1.4 m away, with the panel above it.

In VR, try typing with the ray: S O F A space R E D, then SEND. Or tap a quick button: SOFA RED, CUBE BLUE, TABLE BIG, SPIN CUBE.
